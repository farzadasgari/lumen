## Highlights

- **40 visual combinations** — 10 palettes × light/dark × standard/neon, with
  sidebar, navbar, width, density and RTL as independent options
- **70 pages** — dashboards, applications, a component gallery, forms, tables,
  authentication and error pages
- **Genuinely responsive** — every page designed at 320px, not shrunk down to it
- **WCAG 2.1 AA** — verified with axe-core across every theme and both modes
- **RTL as a first-class feature**, not a flipped stylesheet
- **No framework, no build step, no CDN** — every dependency is vendored

---

## Getting Started

Clone it and open `index.html`. That is the entire setup.

```bash
git clone https://github.com/farzadasgari/lumen.git
cd lumen
```

It runs straight from the file system, so no server is required. To serve it
anyway:

```bash
python3 -m http.server 8000
```
